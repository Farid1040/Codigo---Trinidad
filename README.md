# Programas en Turbo Pascal

Este repositorio contiene dos ejemplos básicos escritos en Pascal:

- `hola_mundo.pas`: muestra el mensaje **Hola Mundo**.
- `operaciones.pas`: solicita dos números y muestra la suma, resta, multiplicación y división. El código está organizado mediante varios `procedure` y evita la división entre cero.

## Compilación y ejecución

En Turbo Pascal, abra cada archivo desde el IDE y seleccione **Run > Run**. También puede compilar los programas con Free Pascal:

```bash
fpc hola_mundo.pas
fpc operaciones.pas
```

Después ejecute el archivo generado correspondiente a su sistema operativo.

## Nota

Los mensajes y comentarios del código se mantienen sin caracteres acentuados para facilitar la compatibilidad con las configuraciones antiguas de Turbo Pascal.
